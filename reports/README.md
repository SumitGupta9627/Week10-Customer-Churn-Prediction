# Reports Folder

This folder contains the reports for the Customer Churn Prediction project.

## Files

- `model_evaluation_report.md` — Contains model performance metrics, results interpretation, and limitations.
- `validation_evidence.md` — Documents notebook execution and validation checks.

## Instructions

Run `churn_prediction_pipeline.ipynb` to generate and verify the model results. If the dataset or model changes, update the evaluation report accordingly.
